enumValueOne field value, tagged with its kind

One field value, tagged with its kind. The kind travels with the value, so a message that keys its values by field number and one that has a struct field per field answer the same questions about it. A composite value holds a reference to a list, map or message, so mutation through it is visible to the message that owns it. The accessors abort when the value is not the kind asked for, as an out-of-range index does, and `map_key` refuses a value that is not one of the six key kinds.

traitMessageA message instance, reachable only through its descriptor

A message instance, reachable only through its descriptor. `has` answers whether a field carries a value. A repeated or map field carries one when it is non-empty, a field with presence when it is set, and a field without presence when its value is not the zero of its kind — writing a zero is the same as leaving the field out. Encoders ask `is_populated`, which is the same rule stated once for every implementation.
