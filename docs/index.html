What is in the box

One module, thirteen packages. Import the ones a program needs.

0x08

Binary

Varints, fixed-width numbers, length-delimited values and groups. Unknown fields are kept and written back.

0

Presence

A field without presence is written only when it is not zero, in binary and in JSON alike. optional is what keeps a zero.

{ }

JSON

64-bit integers as strings, enums by name, bytes in base64, and the well-known type forms.

a: 1

Text

The full grammar: groups, lists, separators, octal and hexadecimal literals, comments.

struct

Generated structs

protoc-gen-mbt writes a struct whose fields are the protobuf fields. Repeated becomes Array, map becomes Map, oneof becomes an enum.

desc

Descriptors at run time

A .proto parser builds the descriptor model in memory, so a schema can be read without a code generation step.

reflect

One trait

Encode, decode, size, merge, JSON and text all reach a message through reflect.Message.

Take a message apart

The playground writes a schema to bytes, then reads the bytes back as JSON and text. Every value comes from this library.
