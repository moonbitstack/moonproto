# moonproto

Protocol Buffers for MoonBit: the wire format, the reflective descriptor model,
binary, JSON and text encodings, dynamic messages, the well-known types, and the
`protoc` plugin that generates MoonBit message code.

## Status

The interface is drafted and under review. No implementation has landed yet.

- `docs/design/inventory.md` — every capability the module covers, one row each,
  with where it lives.
- `docs/design/interface.md` — the types, signatures and the mechanism that
  replaces Go's runtime reflection and `unsafe` field access.

## Packages

| Package | Carries |
|:--|:--|
| `wire` | the wire format: tags, varints, fixed-width numbers, length-delimited values, groups, zig-zag, and the reader that reports where it stopped |
| `reflect` | descriptors, `Value`, `Message`, `Enum`, `List`, `Map`, and the global registries |
| `desc` | building runtime descriptors from `FileDescriptorProto`, and converting back |
| `proto` | binary encode and decode, size, merge, clone, equal, reset, extensions, options |
| `json` | the JSON mapping, including `Any` and the well-known types |
| `text` | the text format, including the well-known types |
| `delim` | varint size-delimited messages over a byte stream |
| `dynamic` | messages, enums and extensions built at run time from descriptors |
| `known` | the well-known types and the descriptor, plugin and feature messages, generated by this module's own plugin |
| `gen` | the plugin framework: request in, generated files out |
| `cmd/protoc-gen-mbt` | the `protoc` plugin binary |

The root package is empty; a program imports the subpackages it uses.

## How it fits together

A message type is written by hand or generated by `cmd/protoc-gen-mbt`. It is an
ordinary MoonBit struct, and it implements `reflect.Message`, so the encoders,
the JSON mapping and the dynamic layer all reach its fields through the same
trait. The struct also has a companion `reflect.MessageType`, which the
registries hold so that a type can be found by name — for example when decoding
an `Any`.

Descriptors are immutable and shared. `desc` builds them from a
`FileDescriptorProto`; `reflect` declares what a descriptor exposes; the
encoders never look at a struct's layout, only at its descriptor.

<!-- nocheck -->
```mbt
let msg = HelloRequest::new(name="moon")
let bytes = @proto.encode(msg)
let back = @proto.decode(bytes, HelloRequest::new())
```
