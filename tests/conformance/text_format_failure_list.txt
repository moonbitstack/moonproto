# cases below are the declared unsupported subset, grouped here by cause:
#

#     parsed; the binary form and the text form of ordinary messages are.
#   - Special float spellings other than inf/-inf/nan (PosINF, nAn, huge
#     exponents) and octal integer literals are not accepted.
#   - Statement punctuation beyond one field per line (semicolons, commas
#     inside list values, adjacent string literal concatenation) is not read.
#   - Reserved field names, Any/extension brackets and duplicate-field
#     recovery follow the strict subset rather than C++ text format.
#   - Out-of-range scalar literals are not rejected on the text path.
#
